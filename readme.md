# After School Hub

An after-school online learning platform built with HTML, CSS, JavaScript and Vue.js. Browse educational courses, view course details, track availability and manage items through a shopping cart.

## Repository Structure

The repository is structured as follows:

```text
.
├── README.md
├── index.html
└── assets

    │   └── icons8-physics-100.png
    └── style.css
```
